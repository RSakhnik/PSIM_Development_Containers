# Isolation Probe

Diagnostic Pilot Web extension based on the official ASCON backend.commands.sample and toolbar.extension.sample (SDK 26.19). The same extension identity and assembly name are used in A1, B1 and A2. Version and nonce are returned by compiled backend code on every command invocation. Backend launch ID is generated by the loaded assembly, not read from the uploaded ZIP. It performs no database writes and calls no external service.

Build with build-probe.ps1. ZIP layout is frontend/ plus backend/, matching official SDK samples. Each variant uses a different semver in the Pilot manifest solely to trigger normal extension update; platform packages remain content-addressed.
